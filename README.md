# SimpleAnalysis

Учебная (ознакомительная) практика, МУ им. С.Ю. Витте, направление 38.03.05 «Бизнес-информатика».
Автор – Яцко Сорин.

Программа `simple_analysis.py`:

1. генерирует 1000 целых чисел в диапазоне [−10000; 10000] (зерно – студенческий ID) и сохраняет их
   в `output/dataset.csv` вместе со строками «цифрового мусора»;
2. загружает набор и очищает его (нечисловые, пустые, дробные значения и значения вне диапазона);
3. рассчитывает минимум, максимум, число повторов, сумму, среднее и СКО (`output/statistics.txt`);
4. строит линейный график, гистограмму значений, округлённых до сотен, графики отсортированных рядов;
5. формирует DataFrame, разделяет данные по знаку, считает суммы по диапазонам;
6. загружает второй набор из `output/dataset_2.txt`, объединяет наборы и оценивает корреляцию.

## Запуск

```
python -m venv venv
venv\Scripts\activate        # Linux: source venv/bin/activate
pip install -r requirements.txt
python simple_analysis.py
```

Результаты сохраняются в папку `output/`.
